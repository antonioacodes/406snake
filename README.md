# 406 Snake

Jogo Snake em HTML, CSS e JavaScript puro, pronto para servir como site estático.

## Recursos

- Modos Clássico, Rápido, Impossível e Diário
- Controles por teclado (setas ou WASD) e por toque
- Pontuação e recorde salvos no navegador
- Pausa automática ao trocar de aba
- Efeitos sonoros opcionais
- Layout responsivo

## Executar

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor HTTP.

Na VPS, depois de configurar o domínio para esta pasta, não é necessário compilar nem instalar dependências.

## Controles

- **Setas / WASD:** mover
- **Enter:** iniciar novamente
- **Espaço / Esc:** pausar
- **M:** voltar ao menu

## Experimento Nokia 3D

Abra `nokia-3d-test.html` para testar o jogo com o modelo Nokia 3310 hospedado no Sketchfab.

O laboratório inclui textura dinâmica, inspeção de cliques e materiais, seleção manual do material do LCD e controles 2D de reserva. O carregamento depende de conexão com o Sketchfab.
