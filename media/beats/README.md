# Beats da sala

Coloque os arquivos MP3, WAV, M4A ou OGG diretamente nesta pasta.

Exemplos:
- media/beats/montana.mp3
- media/beats/sistema.mp3
- media/beats/missao.mp3

O nome do arquivo sem extensão aparece no player. Cada entrada na sala embaralha a lista. Anterior/próxima e avanço ao terminar usam a mesma ordem embaralhada. Volume e filtros afetam apenas estes beats.

Com a pasta vazia, o player usa media/room-beat-127.wav. Se quiser manter esse beat junto aos novos, copie-o para esta pasta.

A lista é lida sem cache por beats.php; não é necessário editar código ao adicionar arquivos. Requer PHP no servidor.
